# Runtime 集成约束

本说明用于当前 workflow 代理之间共享约束，不是功能完成证明。具体公开类型以实现代码和对应测试为准。

## 执行顺序

运行层是持久 Core 的消费者，不更换逻辑 Session 身份。开始一次运行时取得带 fence 的 AttemptLease，恢复时不得复用已失效 Worker。先落盘需要对外宣布的事件，后向订阅者发布。磁盘写失败必须停止模型和工具后续操作。

Agent 只注册 Luau 的 `execute_code` 工具。脚本通过宿主 CapabilityHost 调用受控能力；宿主在每次调用前检查 task/session 范围、取消、预算和审批，而不是只在脚本外层检查一次。工具返回的未知结果即使发生于脚本中途，也必须传到 Agent 和持久记录，阻止同次及后续运行。

当前 Agent 的 ToolExecutionStart 在校验/执行前发出，包括最终未执行的调用，恢复边界要保守：不将该事件本身解释为已确认副作用，也不将缺少终态解释为未发生副作用。

## 文件、Git、构建和测试

文件能力由目录句柄限制在显式工作区中，路径参数不能逃逸到宿主其他位置；内存/输出/文件字节数均有限制。文件操作要通过同一审批/预算/事件链。

Git、构建/测试使用预先配置程序和参数模板，由宿主挑选并验证允许字段，不开放任意命令串。构建工具本身执行仓库代码，要按任务权限授权；其权限不能伪装成只读文件能力。进程工作目录、环境、输出上限、超时和取消由 Device 统一执行。

检索、MCP 工具和 Skills 通过宿主已建立的接口注入。内核不为外部宿主重复连接、读取其他 Agent 配置或创建检索服务。

## 接入与恢复

SDK、IPC、TUI、WebUI、可选远程接入使用同一请求/事件语义。协议请求含明确版本和 request_id，过大帧/不兼容版本/无权限/未来游标/错配结果返回错误。断连取消还是后台继续必须显式约定，不以界面断线产生重复任务。事件按持久游标分页或订阅补齐，有界慢消费者得到重新续订提示。

审批从宿主或真实用户输入获得，模型请求次数不构成授权。授权要绑定 Session/任务/能力/范围/有效期；撤销后未启动调用拒绝，正在执行的调用发取消并保守保留未知结果。

模块/强流程绑定由持久状态记录。卸载相关模块后冻结其会话。转普通 Chat 只能用户明确确认后 Fork 新 Session，并保留来源，原 Session 不改为普通状态。

可选 Server 不成为本地执行依赖。Device 只出站；WebUI 的本地监听是接入界面，而不是为 Device 管理开入站端口。任何网络路径都不能更换 Device 内容权威，远端密文不会自动覆盖更新的本地版本。

## 证据

保留旧 58 项基线和真实 Magpie 日志。新代码变更生成独立指纹和本次验证记录。所有新增基础能力需要真实执行用例、取消/失败边界及独立复查。平台、真实 Provider、独立两机和合成故障样本分别标注，不互相冒充。
