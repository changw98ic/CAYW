## 用户操作路径

```sh
cayw --ui web --workspace /你的项目
# 或明确开放局域网，仍允许未配置账号访问：
cayw --ui web --lan 192.168.1.10:3080 --workspace /你的项目
```

在运行 CAYW 的电脑打开网页“设置 → 局域网访问账号”，填入账号、新密码、确认密码并保存。当前 LAN 存在时立即生效，并要求原局域网页面重新登录；仅本地模式下明确显示“下次启动局域网模式时启用登录”。本地访问与本机管理始终免登录。没有账号时局域网仍直接放行，不要求初次配置。

LAN 模式同时提供仅回环地址可达的 `local_url` 本机管理入口，默认浏览器打开它。再次执行 `cayw --ui web` 可复用该入口，无需找 token 或临时认证文件。远端网页只显示状态与本机配置指引，保存表单禁用；后端也独立拒绝远端保存，包括已登录远端。CLI `cayw account` 保留为备用首次创建方式；从 CLI 在运行实例外创建文件后，需要重启或在设置页重新保存应用。

## 实现边界

- `cayw-runtime/src/cli_start.rs` 传递宿主指定账号路径、展示本机管理地址，并在重复网页启动时读取当前登录状态，避免沿用启动时的旧状态。默认 TUI/cwd 行为保留。
- `cayw-webui/src/main.rs` 在明确 LAN 模式下配对一个 loopback listener，两个入口复用同一 Gateway、DeviceRouter 和所有权状态；退出同时关闭两个入口。
- `lib.rs` 以 axum 的真实 accepted TCP 对端 `ConnectInfo` 与管理 Host 双重判定本机管理权限。Origin/Sec-Fetch-Site 仍校验；不信任 Forwarded/X-Forwarded-For，不以 Host 伪造取得权限。本机管理地址不应由外部代理公开。
- `access.rs` 的账号接口独立于模型工具和 Runtime RPC。账号只写入启动器指定文件，不接受浏览器任意路径。保存使用版本核对、私有文件锁及原子替换，密码为加盐 Argon2id 摘要，文件 0600。账号写入和 LAN 状态更新在同一受控阻塞操作内完成，HTTP 回执中断不会把已经保存的账号留在未应用状态。目录持久化确认失败会保留已应用状态并返回不确定结果，不自动重试。
- `assets/app.js` 显示未配置、已启用、下次 LAN 启用或本机管理限制。双击保存只发一次请求；过期版本返回 409，保持新配置。提交、关闭设置或离开页面清空密码；回执不确定时提示刷新核对，不自动重发。密码和摘要不进入 UI 状态回显、日志、URL 或前端存储。保存后更新暴露提示，未登录远端在下一次请求时显示账号密码登录。
- 修改账号会撤销旧的登录会话；旧密码及配置修改期间正在校验的旧账号不能重新签发有效登录。Runtime Session/Task、预算、插件权限和未知副作用记录不作重置。
